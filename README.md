### Hi, I'm Powfu

AI undergrad working on reinforcement learning and AI agents.<br>
Lately: teaching RL by breaking it on purpose, and making agent runs verifiable.

#### <samp>REINFORCEMENT LEARNING</samp>

- [**BreakRL**](https://github.com/Powfu-zwx/BreakRL) · A bilingual RL textbook, from bandits to GRPO. Each chapter removes one mechanism so you can watch the algorithm fail. [Read it online](https://powfu-zwx.github.io/BreakRL/).
- [**CoopFlow**](https://github.com/Powfu-zwx/CoopFlow) · An RL controller that decides when a team of local LLMs should execute, review, repair or stop, under a hard token budget.

#### <samp>AI AGENTS</samp>

- [**proofline**](https://github.com/Powfu-zwx/proofline) · Verifiable run bundles for LLM and agent executions: hashed, redacted, signable, and diffable in CI.
- [**pi-proofline**](https://github.com/Powfu-zwx/pi-proofline) · Records every run of the pi coding agent as a proofline bundle.
- [**ai-auto-research-skill**](https://github.com/Powfu-zwx/ai-auto-research-skill) · Autonomous research where every claim needs a bounded experiment and an independent evaluator.
- [**clean-first-engineering**](https://github.com/Powfu-zwx/clean-first-engineering) · An agent skill for clean code: fix the root cause, keep one source of truth, leave no residue.
- [**NegotiationForge**](https://github.com/Powfu-zwx/NegotiationForge) · A negotiation simulator with a stateful AI opponent and fork-and-replay from any turn.
- [**PolyAgent**](https://github.com/Powfu-zwx/PolyAgent) · A multi-agent workspace for grounded QA, summaries, formal writing and guided tasks.
